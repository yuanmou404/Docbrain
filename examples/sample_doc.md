# DocBrain 冒烟测试文档

本文件用于首次启动时验证「上传 → 切分 → 检索 → 回答 → 溯源」链路是否通畅。
在 Web UI 左侧上传本文件，等状态显示切分片段数后，可在右侧尝试下面的问题。

## 项目概述

DocBrain 是一个完全本地运行的文档问答系统。
系统核心目标是数据不出机器，所有解析、嵌入、检索与生成均在本机完成，
不需要调用任何云端 API。

## 技术架构

后端框架采用 FastAPI，向量数据库使用 Qdrant，嵌入模型为 BGE-M3，输出 1024 维向量。
生成模型使用 Ollama 托管的 qwen2.5:7b，通过本地 11434 端口调用。
重排模型为 bge-reranker-v2-m3，首次使用会自动下载到本地 data/models 目录。

## 检索策略

系统采用 BM25 稀疏检索与向量稠密检索双路召回，再经 RRF 融合排序（k=60）。
融合后使用 cross-encoder 模型 bge-reranker-v2-m3 进行精排，取前若干个片段送入生成模型。
当重排最高分低于拒答阈值（默认 0.08）时，系统判定证据不足，直接拒答而不调用大模型，
避免模型凭空编造。

## 支持格式

系统支持 PDF、Word、Markdown 与网页四种格式的解析。
扫描件走 OCR 分支，文本层过少的页面自动判定为扫描页并触发 rapidocr 识别，
再由 LLM 做形近字与断行纠错。
